# 🤖 SAC Inteligente & Análise de Sentimento para PMEs

Uma aplicação web inteligente desenvolvida em Python e Streamlit que utiliza a Inteligência Artificial do Google Gemini para automatizar a triagem de feedbacks, avaliações e mensagens de clientes de pequenas e médias empresas (PMEs).

---

## 💡 O Problema
Micro e pequenas empresas recebem diariamente dezenas de mensagens e avaliações (WhatsApp, Instagram, Google Meu Negócio). Os gestores perdem horas preciosas a ler tudo manualmente, correndo o risco de deixar passar reclamações graves que resultam na perda de clientes.

## 🚀 A Solução
Este projeto oferece um painel interativo onde o empresário pode inserir feedbacks e obter instantaneamente:
- **Classificação de Sentimento:** Identifica se o tom é Positivo, Neutro ou Crítico.
- **Categorização Automática:** Agrupa o problema (Ex: Entrega, Atendimento, Qualidade, Preço).
- **Alerta de Urgência:** Sinaliza imediatamente casos críticos que exigem intervenção imediata do gestor.
- **Resumo Executivo:** Gera um resumo de uma linha focado na tomada de decisão rápida.

---

## 🛠️ Tecnologias Utilizadas
* **Python** (Lógica principal)
* **Streamlit** (Interface gráfica web interativa)
* **Google GenAI SDK** (Integração com os modelos Gemini)
* **Pandas** (Manipulação e estruturação de dados)
